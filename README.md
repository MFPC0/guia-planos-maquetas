# Guía de planos para maquetas

Qué planos, medidas y datos enviar para generar una maqueta arquitectónica impresa en 3D de forma exacta, sin rondas de preguntas.

- Ver en línea: https://mfpc0.github.io/guia-planos-maquetas/
- Descargar en PDF: [Guia_de_planos_para_maquetas.pdf](Guia_de_planos_para_maquetas.pdf)

## Plantillas

| Archivo | Qué es |
|---|---|
| [plantilla_maqueta.dwg](plantillas/plantilla_maqueta.dwg) / [.dwt](plantillas/plantilla_maqueta.dwt) / [.dxf](plantillas/plantilla_maqueta.dxf) | Capas `MQ-`, bloques de vanos con datos y biblioteca de muebles, en metros |
